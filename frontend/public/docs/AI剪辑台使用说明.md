# AI 剪辑台使用说明

AI 剪辑台（路由 `/ai-editing`）是项目内置的剪辑 Agent 工作台：你在页面里用自然语言下达剪辑意图，由剪辑 AI Agent 直接读写任务的剪辑工程（`project.json` / `assets.json`），完成后保存项目快照，供工作流后续节点继续渲染或发布。

剪辑台本体是一个独立进程（OpenChatCut，端口 5199），由后端通过 `/openchatcut` 反代、以新标签页方式打开，不做 iframe 内嵌。

## 1. 启用前提

剪辑台需要先启动服务并完成配置：

1. **服务进程**：由 Manager（`http://localhost:18001`）统一拉起。可在剪辑台页面顶部的服务卡片里直接「启动 / 重启 / 停止」，也可在设置页或 Manager 面板操作。
2. **Agent 大模型**：剪辑台默认直连本项目 LLM 路由器（`http://localhost:8800/v1`）。在设置页配置路由器的策略与密钥后即可用；未配置时剪辑 Agent 无法对话。
3. **生图 / TTS 接口**：剪辑台内的素材生成、语音合成通过主项目桥接端（`/api/openchatcut-bridge/v1`）转发，复用主项目已配置的接口层，无需在剪辑台重复填写密钥。

## 2. 打开方式

- 左侧导航「AI 剪辑台」进入控制页（服务状态、配置、日志、快捷入口）。
- 点击页面内的「打开剪辑台」按钮，会在新标签页打开 `/openchatcut/`。

## 3. 关联任务与剪辑工程

剪辑台以「任务」为单位组织剪辑工程：

1. 在剪辑台中新建或选择一个任务，任务会关联该任务目录下已产出的媒体、字幕与配音素材。
2. 素材统一登记到工程的素材库（`assets.json`），剪辑 Agent 按需引用，不直接改动原始文件。
3. 时间线、字幕样式、音频处理等编辑结果写入剪辑项目（`project.json`）。

## 4. 用剪辑 Agent 剪辑

1. 在对话框中用自然语言描述剪辑意图，例如「把第 3 段的停顿剪掉」「给前 10 秒加一个标题」「统一字幕字号为 32」。
2. Agent 可切换专家角色（通用 / 设计 / 音频 / 剪辑 / 叙事），不同角色侧重不同的检查与执行策略；每轮对话都会按当前项目状态重新构建系统提示词，因此角色切换和项目变更即时生效。
3. 单次会话最多 20 轮工具调用，复杂编排任务建议拆成多次下达，便于逐步校对。

## 5. 保存与回写工作流

1. 编辑完成后在剪辑台保存，项目快照写回该任务。
2. 工作流中的剪辑类节点读取这份快照作为输入，继续执行合成、配音或发布步骤。
3. 后端也提供 `/api/editor` 接口（任务导入 / 工程读写 / 剪辑 Agent 调用），供工作流节点或其他集成直接调用，无需打开页面。

## 6. 常见问题

| 现象 | 处理 |
|---|---|
| 剪辑台打不开 / 502 | 先在页面服务卡片里启动剪辑台进程，再刷新；仍失败查看 Manager 面板日志 |
| Agent 无响应或提示未配置模型 | 检查设置页 LLM 路由器策略是否已选型并可用密钥 |
| 生图 / 配音报接口错误 | 检查设置页对应接口是否启用并配置了真实密钥（桥接端不校验占位密钥） |
| 保存后工作流拿不到工程 | 确认任务 ID 一致，并在工作流中先执行素材登记类节点再执行剪辑类节点 |
