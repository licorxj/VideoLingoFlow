# 快速开始

VideoLingoFlow 的推荐使用顺序是：先统一配置模型能力，再选择和调整工作流，最后完成一次试跑后进入批量生产。

## 1. 配置大模型

打开左侧导航栏的「大模型路由器」。先在「提供商」中添加你要使用的大模型供应商，并填写该供应商的 API Key。

再进入「策略」创建模型路由映射。将翻译、字幕优化、标题生成等项目阶段映射到合适的模型。这样工作流中的每个节点都会按统一策略调用模型，不需要在每个项目里重复配置。

## 2. 配置能力接口

打开「全局设置」，按你的工作流需求配置以下接口：

- ASR 语音识别：用于从视频或音频中识别原始字幕。
- TTS 语音合成：用于生成目标语言配音。
- 图像生成：用于生成视频封面或配图。

使用云端供应商时，必须先在对应接口中填写有效的 API Key 并完成连通性测试。使用开源 TTS 模型时，建议安装 LcTTSHub 整合包，其中包含常用的热门 TTS 模型。下载地址：<https://github.com/licorxj/videolingo-billing-core/blob/main/.github/workflows/build-release.yml>。

## 3. 选择并调整工作流

回到「工作流编排」，选择适合当前内容的工作流。检查每个功能节点是否符合实际需要：不需要的节点可以删除，需要的步骤可以自行添加。

「共享社区」提供其他创作者分享的节点和工作流，可直接导入工作台。你也可以将验证成熟的自定义节点或工作流发布到社区。

## 4. 试跑后批量执行

先用一条代表性素材执行完整工作流，确认识别、翻译、配音、字幕、合成等产物正常。流程跑通后，进入「批量工作台」创建批量任务，导入多条素材并复用已经验证的工作流，完成规模化处理。
