# 项目目录功能说明（面向智能体）

> 本文档**逐目录/逐模块**说明 VideoLingoFlow 各文件夹与关键文件的职责，帮助智能体快速定位代码、找到功能入口。
> 与[项目架构.md](项目架构.md)配合使用：架构文档讲「系统怎么运转」，本文档讲「东西在哪里」。

---

## 1. 后端（backend/）

### 1.1 `backend/api/` — 全部 REST / WebSocket 路由（按前缀分类）

| 文件 | 前缀 | 功能 |
|---|---|---|
| `tasks.py` | `/api/tasks` | 旧版任务 API（任务详情/工作流/产物/删除），`DELETE /api/tasks/{id}` 删除任务+文件夹 |
| `workflows.py` | `/api/workflows` | **工作流编排核心**：保存/列表/执行（execute）/单节点执行（execute-node）/调试任务（debug-task，POST）/新建一般任务（spawn-task）/另存为全局（save-as-global）/状态/删除（级联删绑定任务） |
| `batch.py` | `/api/batch` | 批量工作台：创建批次/启动/停止/删除（整批与选中）/同步工作流/追加任务/重试/继续 |
| `history.py` | `/api/history` | 历史项目列表（只显示 succeeded/failed 终态任务） |
| `node_types.py` | `/api/node-types` | 内置/自定义节点类型注册表（节点管理器、社区导入依赖它） |
| `settings.py` | `/api/settings` | 全局设置（LLM/ASR/TTS/生图/分离/字幕样式/UI 等配置读写） |
| `prompts.py` | `/api/prompts` | 提示词模板管理 |
| `subtitle_presets.py` | `/api/subtitle-presets` | 字幕样式预设（烧录样式） |
| `subtitle_preview.py` | `/api/subtitle-preview` | 字幕预览渲染 |
| `file_browser.py` | `/api/files` | 文件浏览（本地路径选择器） |
| `llm.py` | `/api/llm` | LLM 调用接口 |
| `tts_interfaces.py` | `/api/tts-interfaces`、`/api/tts-voices` | TTS 引擎/接口/音色管理 |
| `asr_interfaces.py` | `/api/asr-interfaces` | ASR 引擎/接口管理 |
| `imagegen_interfaces.py` | `/api/imagegen-interfaces` | 生图引擎/接口管理 |
| `separation_interfaces.py` | `/api/separation-interfaces` | 人声分离引擎/接口管理 |
| `publish.py` | `/api/publish` | 多平台发布（素材/草稿/标签/历史） |
| `subscription.py` | `/api/subscription` | 订阅/授权/额度 |
| `voiceforge.py`、`voiceforge_ws.py` | `/api/voiceforge`、`/ws/voiceforge` | **晴沐配音谷**：项目/章节/角色/音色/资产/情感标签 + WebSocket 进度 |
| `editor.py`、`editor_agent.py` | `/api/editor` | 剪辑工作台：任务导入/工程 + 剪辑 AI Agent（文字指令剪辑） |
| `cutia.py` | `/api/cutia` | Cutia 编辑器桥接（端口 4100） |
| `aigc_capabilities.py` | `/api/aigc-capabilities` | AIGC 能力（ComfyUI/即梦/RunningHub）查询 |
| `logs.py` | `/ws/logs` | 后台日志实时流 |
| `ws.py` | `/ws/tasks/{id}` | **任务状态实时推送**（节点状态/进度事件） |
| `ws_queue.py` | — | WebSocket 连接管理工具 |
| `control_plane.py` | `/api/control` | **多人协作控制面**：用户/角色/项目/成员/工作流版本/审计/申请审批/LAN 与远程开关 |
| `control_plane_assets.py` | `/api/control` | 协作资源中心（项目资产上传/下载/删除） |
| `control_plane_workspace.py` | `/api/control` | 协作任务工作区文件浏览 |
| `collaboration_ws.py` | `/ws/control/*` | 多人协作实时 WebSocket（在线状态/编辑状态） |
| `pi_rpc.py` | `/api/pi` | **小 Pi 智能体**：会话创建/对话（SSE 事件流）/历史/中止/设置 |

### 1.2 `backend/control_plane/` — 控制平面（任务调度的核心）

| 文件 | 职责 |
|---|---|
| `database.py` | SQLAlchemy engine/会话（SQLite WAL，可用 PostgreSQL） |
| `models.py` | 全部 ORM 模型（`cp_*` 表）：Task/TaskNode/User/Role/Project/Asset/Audit… |
| `workflow_runtime.py` | **任务运行时**：`submit_workflow`、`execute_workflow`、`_run_node`、`request_cancel/request_delete`、产物清理、固定调试任务查找 |
| `custom_node_runtime.py` | 节点管理器自定义节点执行：加载定义 JSON 并运行 Python/Shell/LLM/透传节点 |
| `runtime.py` | 状态机转换表、资源令牌（GPU/TTS/LLM/IO）、错误分类、取消/超时异常 |
| `celery_runtime.py` | Celery broker 封装、任务投递 |
| `step_worker.py` | process 域节点的子进程入口（读取 args → 跑步骤 → pickle 结果） |
| `security.py` | 多人协作鉴权：密码/会话/角色/项目权限/审计 |
| `repository.py` | 任务仓库（旧前端兼容读取） |
| `assets.py` / `checkpoints.py` | 资产/检查点服务 |
| `backup.py` / `compat.py` / `legacy_import.py` | 备份恢复 / 旧数据兼容 / 历史导入 |
| `runtime_flags.py` | 远程模式运行时开关 |

### 1.3 `backend/engine/` — 执行引擎

| 文件 | 职责 |
|---|---|
| `batch_executor.py` | **批量执行器**：批次创建/投递循环（限流+间隔）/停止/删除/重试 |
| `step_pipeline.py` / `step_runner.py` | 步骤流水线 / 步骤执行器 |
| `task_manager.py` / `task_recorder.py` | 任务管理 / 记录 |
| `thread_scheduler.py` | 旧线程调度器（兼容） |
| `artifact_detector.py` | 产物检测 |

### 1.4 `backend/steps/` — 40+ 节点执行步骤

每个文件一个节点步骤（继承 `BaseStep`，实现 `check_artifact`/`validate_inputs`/`run`），`step_registry.py` 做 id → 实例映射。命名 `sNN_名称.py` 或 `s_节点id.py`。**新建节点规范见《节点新建规范指南.md》。**

### 1.5 `backend/config/` — 配置与定义

| 文件/目录 | 职责 |
|---|---|
| `builtin_node_types.py` | **内置节点类型定义**（id/端口/执行域/配置项） |
| `node_schema.py` | 自定义节点字段校验 schema |
| `workflows/*.json` | 全局工作流文件（type:"user"） |
| `node_types/{id}.json` | 自定义节点定义（节点管理器创建） |
| `deleted_builtin_node_ids.json` | 已删除内置节点的持久化隐藏清单（按需生成） |
| `config.yaml` | 全局配置（接口/模型/批量/pi 等） |
| `config_manager.py` | 配置读写（`config.get(key)`） |
| `subtitle_presets/` | 字幕样式预设 |
| `*_interfaces.json` | ASR/TTS/生图/分离接口配置 |
| `workflow_groups.json` | 工作流分组（编排页侧栏） |

### 1.6 能力域模块

| 目录 | 功能 |
|---|---|
| `backend/llm/` | LLM 客户端（llm_client + response_parser） |
| `backend/asr/` | ASR 引擎族（whisperx/funasr/qwen3/elevenlabs + VAD + 对齐） |
| `backend/tts/` | TTS 引擎族（edge/minimax/mimotts + 接口管理） |
| `backend/imagegen/` | 生图引擎族（bailian/kieai + SDK） |
| `backend/separation/` | 人声/音轨分离（demucs/spleeter/bs_roformer/generic） |
| `backend/voiceforge/` | **晴沐配音谷**：独立 DB + 资产/音色/文本处理 + Celery 任务 |
| `backend/aigc/` | AIGC 服务（ComfyUI/即梦/RunningHub） |
| `backend/publish/` | 多平台发布（Social MCP 客户端 + 平台配置） |
| `backend/editor/` | 剪辑工作台 + 剪辑 AI Agent（agent/service.py） |
| `backend/pi_rpc/` | **小 Pi 桥接**（session 管理、RPC client，驱动 thirdparty/pi） |
| `backend/gpu_service/` | 可选 GPU lane 服务：Redis 队列、显存监测、ASR/分离任务调度 |
| `backend/auth/` | 订阅/授权守卫（subscription_guard、cloud_auth） |
| `backend/utils/` | 工具（ffmpeg 封装、响度、字幕样式、音频分段/变速、视频处理…） |
| `backend/workflow_validation.py` | 工作流规范化（`normalize_workflow`：端口校验/迁移/补 position） |

### 1.7 入口文件

| 文件 | 职责 |
|---|---|
| `main.py` | FastAPI 入口（CORS/中间件/路由挂载/静态托管，端口 11001） |
| `manager.py` | 进程管理器（拉起/重启/停止各服务，端口 18001） |
| `installer.py` | 依赖安装脚本 |

| 路由 | 页面 | 功能 |

| `/history` | History | 历史项目（终态任务卡片/搜索/批量删除） |

### 2.2 组件（`src/components/`）

| 目录 | 说明 |
|---|---|
| `workflow/` | WorkflowEditor、WorkflowNode、NodePalette、NodeManager、ExecutionModeModal 等（工作流编排核心） |
| `batch/` | 批量卡片/任务项/创建对话框 |
| `collaboration/` | CollaborationOverview（成员/审批）、ResourceCenter（资产/工作区文件） |
| `community/` | 社区资源卡片/分享打包/导入/身份管理 |

| `settings/` | 各设置面板（LLM/ASR/TTS/生图/分离/字幕/Agent…） |
| `task/`、`ui/`、`shared/`、`layout/` | 任务卡片、基础 UI、共享组件、布局（Sidebar/Header） |

### 2.3 API 客户端（`src/api/`）

与后端路由一一对应：`tasks.ts`、`workflows`（在 `client.ts` 直连）、`batch.ts`、`history.ts`、`controlPlane.ts`、`collaboration.ts`、`community.ts`、`piRpc.ts`、`voiceforge.ts`、`publish.ts`、`settings.ts`、`nodeTypes.ts`、`subscription.ts`、`taskMonitor.ts`（WS 状态轮询）、`ws.ts`。

### 2.4 状态与工具（`src/stores/`、`src/lib/`）

- `stores/`：zustand——`workflowStore`（画布状态）、`taskStore`、`configStore`、`controlStore`（协作会话）、`projectStore`、`subscriptionStore`。
- `lib/`：`workflowTypes.ts`（节点类型/端口类型/连线规则）、`fallbackNodeTypes.ts`（后端不可用时的节点兜底副本）、`snapshot.ts`、`canvasPreview.ts`、`languages.ts` 等。

## 4. 根目录脚本

## 5. 功能 → 代码定位速查

| 想改什么 | 去哪里 |
|---|---|
| 新增/修改能力接口（ASR/TTS/生图/分离） | `backend/config/*_interfaces.json` + `backend/{asr,tts,imagegen,separation}/*_interface_manager.py` + `backend/api/*_interfaces.py`（规范见《接口添加指南.md》） |
| 工作流编排/执行/节点边界 | `backend/api/workflows.py` + `backend/control_plane/workflow_runtime.py` |
| 批量任务 | `backend/engine/batch_executor.py` + `backend/api/batch.py` |
| 新增/修改节点 | `backend/config/builtin_node_types.py` + `backend/steps/` + `backend/steps/step_registry.py` |
| 多人协作（用户/角色/项目/资源） | `backend/api/control_plane*.py` + `backend/control_plane/security.py` + `backend/control_plane/models.py` |
| 共享社区 | `backend/api/community.py` + `cloudflare/src/index.js` |
| 小 Pi | `backend/api/pi_rpc.py` + `backend/pi_rpc/` + `frontend/components/agent/` |
| 配音谷 | `backend/api/voiceforge*.py` + `backend/voiceforge/` + `frontend/pages/VoiceForge*` |
| 多平台发布 | `backend/api/publish.py` + `backend/publish/` |
| 任务状态实时刷新 | `backend/api/ws.py` + 前端 `taskMonitor.ts` |
| 全局配置 | `backend/config/config.yaml` + `backend/config/config_manager.py` |
