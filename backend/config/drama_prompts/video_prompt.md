# 视频提示词

本规范用于**拼装**分镜段落的图生视频提示词（不是让模型自由发挥）。
节点按此规范把分镜的 `scene_descriptions` / `dialogues` 组装为提示词。

## 参数（frontmatter，随文件生效）

上方 frontmatter 参数由 `s_agi_comic.py::S_AGI_ShotVideo` 运行时读取
（`_video_prompt_rules()`），**改本文件即改拼装行为**；节点显式配置同名项时以节点配置为准。
文件缺失或参数非法时回退内置默认值，流程不中断。

| 参数 | 默认 | 作用 |
|---|---|---|
| `segment_seconds` | `3` | 每段秒数，段头时间轴按此步进 |
| `join_word` | `切到` | 第 2 段起的衔接词；留空则不写 |
| `reference_prefix` | `@` | 角色引用前缀；留空则不写 @ 引用 |
| `time_range_format` | `{start}-{end}秒：` | 段头模板，可用 `{start}` / `{end}` |
| `include_dialogues` | `true` | 是否把 `dialogues` 并入提示词 |
| `dialogue_format` | `，{character}说：「{content}」` | 台词拼装模板，可用 `{character}` / `{content}` |
| `scene_join_fallback` | `；` | 无分段结构（无 `scene_descriptions`）时的兜底连接符 |
| `camera_position` | `head` | `camera_prompt` 位置：`head` / `tail` / `none` |

## 格式

按 **3 秒为一段**，每段单独一行、用换行分隔，时间范围连续衔接（无重叠、无空缺）：

```
0-3秒：@空间站走廊，中景固定镜头，@林远站在主控台前，手指快速滑动面板，眉头紧锁。
3-6秒：切到侧脸特写，@苏晓盯着闪烁的屏幕，呼吸变重。
6-9秒：切回中景，@苏晓说：「备用信道还有噪声。」头顶灯管冷白光，屏幕蓝光打在两人脸上。
```

## 段内结构（顺序固定，可省略无内容的项，但动作必须有）

**时间范围 ＋ 场景@引用 ＋ 景别/运镜 ＋ 角色@引用＋主体动作·表情 ＋ 对白/旁白 ＋ 氛围光线**

- **第一段必须建立空间**：场景 + 机位 + 角色位置，让观众一眼知道在哪、看谁
- **切镜**：用"切到/切回"开头并重新交代景别与主体
- **每段一个主动作**，动词具体可见（走、转身、抬头、攥紧、停顿）
- **每段一个镜头状态**（近景/中景/全景/特写；固定/推/拉/摇/跟）
- **对白**：写「角色名说：「台词」」；3 秒念不完的长台词拆到多段

## 映射规则

- `scene_descriptions` 的每个子镜头映射为 **1-2 个连续的 3 秒段**，顺序一致、不新增子镜头
- `dialogues` 分配到对应子镜头的段；**不创作新台词**
- 段落有可选 `【运镜】`/`【时长】` 标记时，分别用于段内镜头状态与总段数

## 引用规则

- `@场景名` / `@角色名` 必须与项目中的名字**完全一致**（不要缩写、不要加符号）
- **每段至少一个 @ 引用**锚定画面；只引用该分镜已绑定的角色与场景

## 时间轴

- 段数 = 段落时长 ÷ 3 秒（向上取整），各段时间范围相加等于总时长
- 节奏：第一段建立 → 中段推进 → 末段落到结果或情绪点

## 禁止事项

- 跨场景切换、闪回（一个段落只在一个场景内）
- 引用列表之外的名字
- 抽象情绪词、文学化比喻、英文混写
- 在视频提示词里写"台词内容"而不标说话人
