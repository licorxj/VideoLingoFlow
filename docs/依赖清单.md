# 依赖清单（三大系统）

> 最后修订: 2026-08-14
> 依据: 对 `backend/`、`installer/`、`scripts/`、`control_plane/` 全部 .py 做 AST import 扫描 +
> 保留包硬依赖闭包递归分析（155 包）+ 运行时机制核查（子进程 CLI / FastAPI WebSocket / venv 实测）。

## 系统总览

| 系统 | 依赖声明文件 | 安装入口 | 运行环境 |
|------|-------------|---------|---------|
| 主后端 VideoLingoFlow | `backend/requirements.txt` + `backend/requirements-voiceforge.txt` + PyTorch 三件套 | `installer/install.py` → `backend/installer.py` | `venv312`（Windows / Linux / macOS） |

> 存在同模块提供方冲突时（见「平台适配与冲突」），后安装者覆盖前安装者。

### 1.2 本次移除的依赖（27 项，2026-08-14 瘦身）

`fastapi-cli fastapi-sso pytorch-wpe pytorch-complex gradio gradio_client moviepy ffmpeg-python ass pyparsing pedalboard typer opencc-python-reimplemented langdetect psutil py-cpuinfo gputil python-jose httpx-sse peft bitsandbytes accelerate diffusers imageio imageio-ffmpeg opencv-python` + 声明冗余的 `markupsafe`（jinja2 传递提供）。

- 移除依据：项目源码无直接 import；不处于任何保留包的硬依赖闭包内；无子进程/运行时调用。
- 保留 `opencv-python-headless`（与 `opencv-python` 二选一，headless 无 GUI 依赖）。
- 特别说明：`pytorch-wpe`/`pytorch-complex` 此前即未装入 venv（funasr 自身依赖 `torch_complex` 分发包工作），移除声明不影响运行。

### 1.3 平台适配

| 组件 | Windows | Linux | macOS |
|------|---------|-------|-------|
| PyTorch 三件套 | `torch==2.8.0+cuXXX`（installer.py 按 CUDA 检测选 cu128/cu126/cu124/cu118/cpu） | 同 Windows（有 NVIDIA GPU 时选 CUDA wheel，否则 +cpu） | 无 CUDA，installer.py 自动走 PyPI 官方 wheel（含 MPS） |
| uvicorn | [standard] 含 httptools/watchfiles | [standard] 含 uvloop+httptools | [standard] 含 uvloop |
| opencv-python-headless | wheel | wheel | wheel |
| demucs / librosa | wheel（需 ffmpeg 二进制） | wheel（需 ffmpeg） | wheel（需 ffmpeg，Apple Silicon 有 wheel） |
| curl_cffi | wheel | wheel | wheel |

### 1.4 安装入口

```
installer/install.py  → 步骤[5/9] 运行 backend/installer.py
backend/installer.py  → ① 检测 CUDA → ② 安装 PyTorch 三件套（平台适配） → ③ pip install -r requirements.txt → ④ verify_installation 验证
```

verify_installation 验证项：torch / torchvision / torchaudio / fastapi / uvicorn / cv2 / PIL / yt_dlp。

## 三、social-auto-upload-web-ui 后端

声明文件：`thirdparty/social-auto-upload-web-ui/backend/requirements.txt`

| 包 | 说明 |
|----|------|
| Flask[async], flask-cors, waitress | Web 服务（waitress 为跨平台 WSGI） |
| requests, boto3, xhs | 平台上传 SDK |
| opencv-python, Pillow | 图像处理（**完整 GUI 版**，见冲突说明） |
| qrcode, segno | 二维码 |
| loguru, cloakbrowser | 日志与隐匿浏览器封装 |

### 平台适配与冲突（重要）

- `opencv-python`（social 所需）与主后端的 `opencv-python-headless` **都提供 cv2 模块**，且装入同一 venv。
  主后端先装 headless，social 后装完整版 → 最终生效的是完整版 cv2（带 GUI 依赖）。
  若需无 GUI 环境（纯服务器跑主后端），可把 social 的 `opencv-python` 改为 `opencv-python-headless`。
- `cloakbrowser` pip 包与 `thirdparty/cloakbrowser` 二进制目录为两套机制，均需存在。
- 安装入口：`install_thirdparty.py` → `ensure_backend_pip()`。

```powershell
# 验证依赖完整性与运行
venv312\Scripts\python.exe -m pip check
venv312\Scripts\python.exe -c "from backend.main import app; from funasr import AutoModel; import faster_whisper, cv2, edge_tts, librosa, demucs, yt_dlp; print('OK')"
```

卸载失败恢复：`pip install -r backend/requirements.txt`。
