### 1.5 分发包内置依赖（构建期烘焙，非 pip 安装）

Windows 整合包（`Windows分发包-VideoLingoFlow-x.x.x`）的 `payload/venv312` 在构建期通过 `installer/bake_cuda_torch.py` 从开发 venv 烘焙进以下额外依赖，**不通过 `requirements.txt` / `installer.py` 安装**：

| 依赖 | 位置 | 说明 |
|------|------|------|
| CUDA 版 PyTorch 三件套 | `payload/venv312/Lib/site-packages/{torch,torchvision,torchaudio}`（另含 `torchgen`，torch 2.8 的运行期依赖） | 含 CUDA 12.8 运行时 DLL（内置于 `torch/lib`），约 7GB。CUDA 用户开箱即用、无需联网；CPU 用户安装时由安装器自动卸载 CUDA 版并改装随包附送的 CPU wheel（`payload/wheels/torch-2.8.0+cpu-*.whl`） |
| transformers 运行期补丁 | `payload/venv312/packages/transformers-560` | transformers 5.6.0 + huggingface_hub 1.9.0 + numba 0.60.0 + httpx / httpcore / h11 + regex 等。**供 MOSS ASR（`backend/asr/asr_moss.py`）在运行时以 `sys.path` 前置方式加载**，避免与全局 `transformers 4.57.6` 冲突。该目录必须位于 `venv312/packages/transformers-560`，缺失则 MOSS 引擎回退到全局 transformers 而无法正常推理 |

- 烘焙入口：`installer/bake_cuda_torch.py`（CUDA torch + torchgen + transformers 补丁目录一并复制）；CPU wheel 下载入口：`installer/fetch_torch_wheels.py`。
- 重建分发包：`build/build_dist.py --archive --skip-check`。
- 注：全局 `site-packages` 仍保留 `transformers 4.57.6`（funasr 所需），与补丁目录互不干扰——补丁仅在 MOSS 引擎进程内前置生效。

### 1.6 sherpa-onnx 说明（模型自动下载 / GPU）

**模型自动下载**（`backend/asr/sherpa_models.py`）：

- 缓存目录沿用既有约定：`MODEL_CACHE_DIR` 或项目根 `_model_cache`，本引擎落在 `_model_cache/sherpa-onnx/<model-id>/`。
- 识别模型走 HuggingFace 仓库 `csukuangfj/*`，默认镜像 `https://hf-mirror.com`（可用 `HF_ENDPOINT` 覆盖）；国内直连 huggingface.co 基本不可用。
- 默认下载 `model.int8.onnx`（SenseVoice 约 228MB；fp32 版 `model.onnx` 约 940MB，可在接口配置 `model_file` 切换）。
- VAD 模型 `silero_vad_v5.onnx`（2.2MB）来自 GitHub release `asr-models`（已实测直连可用；可用 `SHERPA_GH_MIRROR` 配镜像前缀）。
- 下载带 `.part` 断点续传与进度回调；请求带 User-Agent（镜像/CDN 对无 UA 请求返回 403）。

**可选 ASR 模型**（`sherpa_models.MODEL_REGISTRY`，均实测可下载；权重默认取 int8，可用 `variant=fp32` 切换）：

| 模型 ID | 体积 | 语种 | 词级时间戳（实测） | 备注 |
|---------|------|------|------------------|------|
| `sense-voice-zh-en-ja-ko-yue` | 228MB | 中英日韩粤 | ✅ 有 | 默认；自带标点/语种/情感标签 |
| `sense-voice-funasr-nano` | 252MB | 中英日 | ✅ 有 | 与 torch 版 funasr_nano 同源，ONNX 无 torch 依赖 |
| `paraformer-zh` | 217MB（fp32 785MB） | 中英 | ❌ **int8 无 token 时间戳** | 识别质量好，但缺词级时间戳时会自动触发对齐补跑 |
| `paraformer-zh-small` | ~74MB | 中英 | ❌ 同上 | 轻量档 |
| `dolphin-base-multi-lang` | 99MB | 多语种 | ✅ 有 | 最轻的多语模型，CPU 友好 |
| `whisper-small` | 358MB（encoder+decoder） | 多语 99 种 | ❌ 官方 decoder 未导出 cross-attention | 输出为**繁体中文**；可用 `task=translate` 直接出英文 |

- 多文件模型（whisper / fire-red）通过 `weights` 字段按 `encoder`/`decoder` 角色声明；whisper 的词表名为 `small-tokens.txt`（已配置 `tokens` 字段）。
- `s02_asr` 的对齐触发已改为**结果级判定**：接口声明有词级能力但本次结果无 `words` 时，仍会补跑对齐阶段（避免静默退化为段级估算）。

**后处理配套模型**（`backend/asr/sherpa_postprocess.py`，三个组件均已实测通过）：

| 能力 | 引擎名 | 模型来源 | 体积 | 接入点 |
|------|--------|----------|------|--------|
| VAD | `sherpa` | GitHub `asr-models/silero_vad_v5.onnx` | 2.2MB | `vad_processor.get_vad_processor` + `asr_base._apply_vad` 兜底链 |
| 标点恢复 | `sherpa` | HF `csukuangfj/sherpa-onnx-punct-ct-transformer-zh-en-vocab272727-2024-04-12/model.onnx` | 281MB | `asr_base._apply_punctuation` |
| 说话人分离 | `sherpa` | GitHub `speaker-segmentation-models/pyannote-segmentation-3-0` + `speaker-recongition-models/3dspeaker_..._eres2net_base_sv` | 1.5MB + 声纹 | `asr_base._apply_diarization` |

- 说话人聚类阈值（余弦距离，越大越易合并）实测标定：官方 4 说话人样本下 0.5→7 人（过细）、0.8→5 人、**显式给 `num_speakers` 时准确命中 4 人**；默认取 0.75，支持 `num_speakers`/`max_speakers` 传入。
- 前端选项已同步：`ASRSettings.tsx` 与 `fallbackNodeTypes.ts` 的 VAD / 说话人 / 标点下拉均含 `sherpa`。

**GPU**：PyPI 上 `sherpa-onnx` 无 `+cuda` 版本，只有 CPU EP。需要 GPU 时二选一：

1. 换官方预编译 GPU SDK（`sherpa-onnx-v1.13.x-cuda-12.x-cudnn-9.x-onnxruntime1.28.x-win-x64-cuda.tar.bz2`）中的共享库，Python 侧 ctypes 直接调 C API（无需编译）；
2. 自行用 `SHERPA_ONNX_CMAKE_ARGS="-DSHERPA_ONNX_ENABLE_GPU=ON"` 编译 `+cuda` wheel（需 MSVC/GCC + CMake，成本高）。

当前实现统一按「provider=cuda 优先、无 GPU 版自动回退 cpu」配置，因此 CPU/GPU 两套部署共用同一份引擎代码。

### 平台适配与冲突（重要）

- `opencv-python`（social 所需）与主后端的 `opencv-python-headless` **都提供 cv2 模块**，且装入同一 venv。
  主后端先装 headless，social 后装完整版 → 最终生效的是完整版 cv2（带 GUI 依赖）。
  若需无 GUI 环境（纯服务器跑主后端），可把 social 的 `opencv-python` 改为 `opencv-python-headless`。
- `cloakbrowser` pip 包与 `thirdparty/cloakbrowser` 二进制目录为两套机制，均需存在。
- 安装入口：`install_thirdparty.py` → `ensure_backend_pip()`。
