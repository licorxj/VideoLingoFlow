# 素材库数据库结构与查询指南

> 本文档说明**公共素材库**的表结构与 `backend/creation` 数据层读写接口,覆盖三部分:
> ① 公共角色库 `cp_characters`;② 图片/视频素材库 `cp_images`/`cp_videos`(存于控制面库 `data/control-plane.db`);
> ③ 音频类素材(音色/音效/背景音乐,存于 voiceforge 库 `voiceforge_data/voiceforge.db`,通过 `vf:` 引用格式定位)。
> 读写脚本:`backend/creation/libraries.py`(三库)、`backend/creation/audio_refs.py`(音频)、`backend/creation/paths.py`(路径约定)。
> AI 创作项目侧如何消费这些素材,见《AI创作项目数据库结构与查询接口指南》。

---

## 1. 总览

| 库 | 表 | 内容 | 模型/脚本 |
|---|---|---|---|
| 控制面库(`data/control-plane.db`) | `cp_characters` | 公共角色库(跨项目共享) | `Character` / `libraries.py` |
| 控制面库 | `cp_images` | 图片素材库 | `ImageAsset` / `libraries.py` |
| 控制面库 | `cp_videos` | 视频素材库 | `VideoAsset` / `libraries.py` |
| voiceforge 库(`voiceforge_data/voiceforge.db`) | `vf_voices` | 音色库 | `audio_refs.py` |
| voiceforge 库 | `vf_assets` | 音频素材库(音效/背景音乐/配音素材) | `audio_refs.py` |
| voiceforge 库 | `vf_exports` | 导出音频片段 | `audio_refs.py` |

三张控制面表均带公共字段:`id`(32 位 uuid hex 主键)、`version`、`created_at`、`updated_at`。

**路径约定**(`backend/creation/paths.py`,读写接口强制执行):

- 公共素材文件落盘在项目根 `data/` 内,数据库记 **`data/` 开头的项目根相对路径**(POSIX 分隔符,禁止 `..`);
- 项目过程文件(运行时项目文件夹内)一律记**绝对路径**;
- `resolve_storage_path()` 读取时统一还原为绝对路径。

## 2. 公共角色库 cp_characters

### 2.1 字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `name` | String(256) | 姓名 |
| `tags` | JSON list | 标签,如 `["主角","冷静"]` |
| `gender` / `age` | String(32) | 性别 / 年龄(字符串) |
| `personality` | Text | 性格 |
| `occupation` | String(128) | 职业 |
| `aliases` | JSON list | 别名 |
| `voice_design` | Text | 音色设计描述 |
| `voice_ref` | String(128) | 音色素材引用,格式 `vf:voices:<id>`(见第 5 节) |
| `images_dir` | String(1024) | 角色多视角图**文件夹**路径,`data/` 相对路径 |
| `origin_creation_id` | String,可空,FK→`cp_creations` | 来源创作项目,项目删除时置空(角色转为公共) |

### 2.2 读写接口

```python
from backend import creation as agi

# 创建:voice_ref 必须是 vf: 引用;images_dir 必须是 data/ 相对路径
role = agi.create_character(
    "林远", tags="主角,冷静", gender="男", age="28",
    personality="外冷内热", occupation="宇航员",
    aliases=["阿远"],
    voice_design="低沉磁性,语速偏慢",
    voice_ref="vf:voices:e36935a12aa04f9eaca938cc3285cf06",
    images_dir="data/characters/linyuan/views",
)

agi.get_character(role["id"])
agi.list_characters(tag="主角", keyword="林远", origin_creation_id="")   # 全部可选过滤
agi.update_character(role["id"], personality="沉稳果决", tags=["主角", "船长"])
agi.delete_character(role["id"])
```

创作项目内的人物可通过 `agi.publish_character_to_library(项目人物id, tags=...)` 一键发布到公共角色库,并自动回写项目人物的 `character_lib_id` 关联。

## 3. 图片素材库 cp_images

### 3.1 字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `path` | String(1024),**唯一** | `data/` 相对路径,重复登记被拦截 |
| `width` / `height` | Integer,可空 | 图片尺寸(px) |
| `aspect_ratio` | String(32) | 图片比例,如 `"16:9"`(最简整数比) |
| `group_tags` | JSON list | 分组标签,如 `["场景","空间站"]` |
| `custom_tags` | JSON list | 自定义标签 |
| `description` | Text | 图片描述 |

### 3.2 读写接口

```python
from backend import creation as agi

img = agi.add_image(
    "data/image_library/场景1.png",       # 也接受绝对路径,自动转相对路径
    group_tags="场景,空间站",              # list 或逗号分隔字符串
    custom_tags=["测试"],
    description="废弃空间站走廊",
    verify=True,                           # 默认校验文件存在
)
# width/height/aspect_ratio 缺省时自动用 PIL 探测补齐(未装 PIL 则保持空)

agi.get_image(img["id"])
agi.list_images(group_tag="空间站", custom_tag="测试", keyword="走廊")
agi.update_image(img["id"], description="走廊场景·更新", group_tags=["场景"])
agi.delete_image(img["id"])
```

## 4. 视频素材库 cp_videos

### 4.1 字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `path` | String(1024),**唯一** | `data/` 相对路径 |
| `width` / `height` | Integer,可空 | 视频尺寸(px) |
| `duration_seconds` | Float,可空 | 时长(秒) |
| `group_tags` / `custom_tags` | JSON list | 分组标签 / 自定义标签 |
| `description` | Text | 视频描述 |

### 4.2 读写接口

```python
from backend import creation as agi

vid = agi.add_video(
    "data/video_library/空镜_城市夜景.mp4",
    group_tags=["空镜"],
    custom_tags="夜景",
    description="城市夜景延时",
    verify=True,
)
# width/height/duration_seconds 缺省时自动用 ffprobe 探测补齐(PATH 中无 ffprobe 则保持空)

agi.get_video(vid["id"])
agi.list_videos(group_tag="空镜", keyword="夜景")
agi.update_video(vid["id"], description="城市夜景延时·替换版")
agi.delete_video(vid["id"])
```

## 5. 音频类素材(voiceforge 库)与 `vf:` 引用格式

音频、音色、音效、背景音乐的素材本体都在 voiceforge 库中。创作项目数据里引用它们时**一律使用带前缀的引用 id**,与文件路径、角色库 id 明确区分:

| 引用格式 | 对应表 | 内容 |
|---|---|---|
| `vf:voices:<id>` | `vf_voices` | 音色 |
| `vf:assets:<id>` | `vf_assets` | 音频素材(音效/背景音乐/配音素材,`asset_type` 区分) |
| `vf:exports:<id>` | `vf_exports` | 导出音频片段 |

### 5.1 生成与解析引用

```python
from backend import creation as agi

ref = agi.make_voice_ref("e36935a1...")          # "vf:voices:e36935a1..."
ref = agi.make_audio_asset_ref("abc123...")      # "vf:assets:abc123..."
ref = agi.make_export_ref("def456...")           # "vf:exports:def456..."

agi.is_audio_ref(ref)                            # 格式校验
table_key, item_id = agi.parse_audio_ref(ref)    # ("assets", "abc123...")
```

### 5.2 反查定位(读)

```python
row = agi.resolve_audio_ref("vf:assets:abc123...")
# 返回 voiceforge 表完整行:storage_key(存储键)、duration、description、tags_json 等

path = agi.audio_ref_abspath("vf:assets:abc123...")
# 直接返回音频文件绝对路径(storage_root / storage_key);无存储键返回 None

agi.list_voices(keyword="温柔")                   # 音色搜索(名称/显示名模糊匹配)
agi.list_audio_assets(asset_type="sfx", keyword="金属")  # 音频素材按类型/关键词过滤
```

### 5.3 登记与维护(写)

```python
recorded = agi.add_audio_asset(
    "金属撞击", "sfx",                     # name, asset_type(如 sfx/bgm/music)
    storage_key="assets/xxx/metal_hit.wav",  # 遵循 voiceforge 存储约定(相对 voiceforge_data/)
    file_name="metal_hit.wav",
    duration=1.5, description="短促金属撞击",
    tags=["金属", "打击"],
)
# 返回 {"id": ..., "ref": "vf:assets:<id>", ...};只登记元数据,不搬动文件

agi.update_audio_asset(recorded["id"], description="更新描述", tags=["金属"], duration=1.6)
agi.delete_audio_asset(recorded["id"])        # 只删登记,不删磁盘文件
```

## 6. 路径工具(`backend/creation/paths.py`)

```python
from backend.creation import paths

paths.PROJECT_ROOT        # 项目根目录
paths.DATA_ROOT           # 项目根/data

paths.normalize_public_path("D:/VideoLingoLc/data/img/a.png")  # → "data/img/a.png"
paths.normalize_public_path("data/img/a.png")                  # → 原样规范化
paths.normalize_runtime_path("D:/runtime/project/s1.png")      # 绝对路径校验后原样返回

paths.resolve_public_path("data/img/a.png")   # → 绝对 Path
paths.resolve_storage_path(value)             # 读库后还原:绝对→原样,相对→按项目根解析
```

非法输入(不在 `data/` 内、含 `..`、过程文件传了相对路径)统一抛 `ValueError`。

## 7. 终端快捷查看(CLI)

```bash
python -m backend.creation.cli character list [关键词]
python -m backend.creation.cli image list [关键词]
```

## 8. 异常速查

| 异常 | 触发场景 |
|---|---|
| `backend.creation.NotFoundError` | id 不存在;音频引用反查不到(`LookupError` 同义场景) |
| `backend.creation.ValidationError` | 名称为空、`voice_ref` 格式错误、路径重复登记、更新字段名不支持 |
| `ValueError` | 路径不规范(见第 6 节);`vf:` 引用格式错误 |
| `FileNotFoundError` | `add_image`/`add_video` 在 `verify=True`(默认)时文件不存在 |
