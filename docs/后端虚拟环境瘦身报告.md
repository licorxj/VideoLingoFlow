## 分析方法

1. 用 `pip list` 导出全部已安装包。
2. 静态扫描 `backend/`、`thirdparty/`、`installer/`、`scripts/` 下所有 `.py` 文件的 `import` 语句，提取顶层模块名。
3. 解析 `requirements.txt`、`requirements-voiceforge.txt` 及 `thirdparty/**/requirements.txt` 的声明依赖。
4. 以「声明依赖 + 代码直接 import 的包 + 运行时/extras 硬依赖（如 `uvicorn[standard]`、`torch` CUDA 相关、`yt-dlp` 插件）」为种子，通过 `importlib.metadata` 递归构建**依赖闭包**。
5. 闭包之外、且无任何反向依赖、且代码中无任何 import 的包，即为「未使用候选」。

> 注：闭包中同时包含约 650 个「未安装的可选依赖名」（如 gradio、vllm、wandb、bitsandbytes 等，来自部分库的 extras 声明），它们不影响可卸载判定；可卸载结论仅基于「已安装 ∩ 不在闭包」且「无反向依赖」。

## 说明与注意事项

- 本报告基于**静态分析 + 依赖闭包**，无法覆盖「运行时动态加载 / 插件自动发现」的全部场景。已对已知动态路径（yt-dlp 插件、uvicorn extras、torch CUDA）做了保留处理。
- `python-bidi` 是否删除取决于是否处理 RTL 语言字幕；如不确定，建议保留。
- 卸载前请用 `pip uninstall -y`（保留 `-y` 谨慎使用）并跑一遍冒烟测试（启动后端 + 一次翻译任务）。
- 虚拟环境瘦身收益有限（上述 7 个均为纯 Python 小包，总体积约数十 MB），真正的体积大头来自 `torch` / `torchvision` / `transformers` / `whisperx` / `funasr` / `onnxruntime` 等，这些为核心功能所必须，不建议裁剪。
