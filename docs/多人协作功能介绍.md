# 多人协作功能介绍

多人协作让剪辑、翻译、配音和运营成员在同一项目中分工处理，并通过项目权限、资源中心和实时状态保持协作过程可追踪。

## 1. 角色与权限

管理员负责成员申请审批、角色分配和项目权限管理。成员只应获得完成当前职责所需的权限，避免无关人员访问素材和项目配置。

## 2. 项目协作

团队成员可以在同一项目中查看任务进度、上传下载素材和产物，并在各自负责的环节继续工作。项目级资源中心集中管理输入素材、字幕、音频、视频和最终交付文件。

## 3. 实时状态与审计

系统通过实时通信同步项目状态和协作进度。重要操作会保留审计记录，便于管理员追踪资源变更和任务处理过程。

## 4. 局域网与远程协作

局域网模式适合办公室或工作室内的设备协作。远程网络协作模式适合异地成员访问主机上的项目，需要主机开启远程协作并按云控安装指南完成网络通道配置。

无论使用哪种模式，任务执行和素材存储仍由主机管理。建议定期备份项目和资源，并为远程访问设置严格的成员权限。
