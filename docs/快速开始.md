# 快速开始

VideoLingoFlow 的推荐使用顺序是：先统一配置模型能力，再选择和调整工作流，最后完成一次试跑后进入批量生产。

## 1. 配置大模型

打开左侧导航栏的「大模型路由器」。先在「平台管理」中添加你要使用的大模型供应商，并填写该供应商的 API Key。可以点击热门平台快速添加。

（1）点击热门平台，填写 API Key 并保存-测试key-获取模型列表,加入需要的模型。

（2）再进入「策略」创建模型路由映射。将翻译、字幕优化、标题生成等项目阶段映射到合适的模型。这样工作流中的每个节点都会按统一策略调用模型，不需要在每个项目里重复配置。可以多模型多apikey进行荷载均衡和故障专用,保证任务稳定执行。

## 2. 配置能力接口

打开「全局设置」，按你的工作流需求配置以下接口：

- ASR 语音识别：用于从视频或音频中识别原始字幕。whisper FUNASR QWEN3-ASR已经内置,初次运行会下载模型,下载出错的到网盘手动下载.下载地址：<https://pan.quark.cn/s/695353a0f0d3>。其他在线ASR或者本地调用其他的asr请配置接口中的key等必要信息.
- TTS 语音合成：用于生成目标语言配音。使用开源 TTS 模型时，建议安装 LcTTSHub 整合包，其中包含常用的热门 TTS 模型,一包解忧。下载地址：<https://pan.quark.cn/s/30c0800fa17b>。
- 图像生成：用于生成视频封面或配图。默认使用的阿里百炼的,请在设置页面的链接访问阿里百炼获取API Key。当然你可以自定义其他你需要的接口.

使用云端供应商时，必须先在对应接口中填写有效的 API Key 并完成连通性测试。

## 3. 选择并调整工作流

回到「工作流编排」，选择适合当前内容的工作流。检查每个功能节点是否符合实际需要：画布中选中节点后按 `Delete` 或 `Backspace` 可删除该次编排中的节点和连线，不会删除节点类型定义；需要的步骤可从节点面板拖入。

连续且连通的多个节点可多选后按 `Ctrl+G` 组成组合节点。组合会保留内部节点与连线，外部输入自动暴露，输出由用户选择暴露；点击组合内的节点可展开并修改其原始设置。组合可解散，也可保存为节点面板中的可复用“组合节点”。

节点管理器删除的是节点类型：删除后引用该类型的工作流不能继续执行。内置节点删除会被持久化隐藏，普通自定义节点删除其定义 JSON；两种操作均应先确认没有需要保留的工作流引用。

「共享社区」提供其他创作者分享的节点和工作流，可直接导入工作台。你也可以将验证成熟的自定义节点或工作流发布到社区。

## 4. 试跑后批量执行

先用一条代表性素材执行完整工作流，确认识别、翻译、配音、字幕、合成等产物正常。流程跑通后，进入「批量工作台」创建批量任务，导入多条素材并复用已经验证的工作流，完成规模化处理。
